# API_DOCUMENTATION.md

Full interactive, always-up-to-date API docs are auto-generated by FastAPI at
`/docs` (Swagger UI) and `/redoc` once the backend is running — this file is
a narrative companion, not a duplicate of the schema.

Base URL: `http://localhost:8000` locally (see `DEPLOYMENT_GUIDE.md` for
other environments).

## `POST /api/detect`

Upload an MRI slice, get back a full detection result.

**Request:** `multipart/form-data`, field name `file`, JPEG or PNG, ≤20MB
(`APP_MAX_UPLOAD_MB`).

**Response:** `200 DetectionDetail`
```json
{
  "id": 14,
  "created_at": "2026-07-21T09:12:00Z",
  "original_filename": "slice_0042.jpg",
  "tumor_detected": true,
  "num_detections": 1,
  "total_tumor_area_pct": 6.42,
  "annotated_image_url": "/api/image/14/annotated",
  "pdf_report_url": "/api/report/14",
  "detections": [
    {
      "class_id": 1,
      "class_name": "positive",
      "confidence": 0.87,
      "bbox_xyxy": [120.5, 88.0, 210.0, 175.5],
      "area_px": 8032.5,
      "area_pct_of_image": 6.42
    }
  ],
  "model_weights": "/app/ml/runs/train/tumor_yolo11/weights/best.pt"
}
```

**Errors:**
| Status | Cause |
|---|---|
| 400 | Unsupported content type (not JPEG/PNG) |
| 413 | File exceeds the upload size limit |
| 503 | Model hasn't finished loading yet (right after container start) |
| 500 | Inference failed (corrupt image, unexpected model error) |

## `GET /api/history?limit=&offset=`

Paginated list of past detections (`DetectionSummary` — no per-box detail,
use the detail endpoint for that). `limit` defaults to 50, capped at 200.

## `GET /api/history/{id}`

Full `DetectionDetail` for one past detection — same shape as the `/detect`
response.

## `DELETE /api/history/{id}`

Deletes the database record. **Does not** currently delete the underlying
files in `storage/` — add a cleanup step there if disk usage matters for
your deployment.

## `GET /api/image/{id}/annotated`

Returns the annotated JPEG for a past detection (boxes drawn on the image
server-side, as opposed to the frontend's client-side overlay used for the
live detect flow).

## `GET /api/report/{id}`

Returns the PDF report (`Content-Disposition: attachment`).

## `GET /api/model/info`

```json
{
  "weights_path": "/app/ml/runs/train/tumor_yolo11/weights/best.pt",
  "class_names": ["negative", "positive"],
  "image_size": 640,
  "conf_threshold": 0.35,
  "iou_threshold": 0.45,
  "device": "cpu"
}
```

## `GET /api/health`

```json
{ "status": "ok", "model_loaded": true }
```
Use this for container healthchecks / uptime monitoring, not for polling
before every request — the frontend only calls it once, on the Model page.

## Authentication

None is implemented in this drop — every endpoint is open. If you deploy
this beyond a local/private demo, add JWT auth (per the original project
brief's constraint: no Auth0/Clerk/Firebase paid tiers) in front of the
`/api/*` routes before exposing it publicly; it isn't wired in yet.
